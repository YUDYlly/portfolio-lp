## カラーパレット

| 用途 | カラー | 備考 |
|------|--------|------|
| メインカラー | ベージュ / ウォームグレー系 | 全体の背景・テキストに使用。木の温もりを意識した配色 |
| アクセントカラー | ゴールド / ブラウン系 | セクションラベル（英語小見出し）に使用。theme-d688ceab クラス |
| テキスト | ダークブラウン〜ブラック | 本文テキスト |

※ CSSはSTUDIOのビルドシステムで管理されており、インラインスタイルでのHEXコード直接記述はなし。色はクラスベース（theme-d688ceab, theme-10a799fe等）で管理。

## フォント

- **日本語**: システムフォント（STUDIO標準）
- **英語ラベル**: システムフォント / 細身のサンセリフ
- **アイコン**: Material Icons + Font Awesome（fa-solid, fa-brands）

## セクション構成（上から順に）

1. **ヘッダー** -- ロゴ（SVG）+ ハンバーガーメニュー + 固定CTA
2. **メインビジュアル（ヒーロー）** -- 背景画像 + 動画（縦型） + キャッチコピー + 3つの特徴バッジ + CTA
3. **体験レッスンCTA** -- 価格訴求（5,500円）+ 予約ボタン
4. **アクセス** -- 地図SVG + 最寄り駅情報 + 駐輪場
5. **About（特長セクション）** -- 5つの特長を画像+テキストの交互レイアウトで紹介
6. **スタジオ写真ギャラリー** -- グリッド配置の施設写真
7. **ビフォーアフター** -- 姿勢比較画像 + 解説テキスト
8. **インストラクター紹介** -- 4名 + 学術監修者1名。写真+資格リスト+自己紹介
9. **料金・プラン** -- 体験/入会金/単発/回数券のテーブル
10. **体験レッスンの流れ** -- 横スクロールのステップカード（01〜04）
11. **Q&A（よくあるご質問）** -- details/summaryによるアコーディオン
12. **お知らせ** -- ブログカード形式（画像+日付+タイトル）
13. **お問い合わせCTA** -- 背景画像 + リンク
14. **店舗情報** -- 住所・営業時間・決済方法・Googleマップ
15. **固定フッターCTA** -- 常時表示の予約バー（LINE + メニュー + 予約ボタン）
16. **フッター** -- ロゴ + ナビリンク + 法的リンク + コピーライト

## レイアウト手法

- **画像+テキスト交互配置**: About セクションで使用。左画像+右テキスト、次は逆、のパターン
- **横スクロールカード**: 体験レッスンの流れ（ステップ01〜04）
- **グリッドギャラリー**: スタジオ写真セクション。大小混在の非対称グリッド
- **スティッキー要素**: 固定フッターCTA（画面下部に常時表示）
- **セクション区切り**: 英語ラベル（Access, About, Plan等）+ 日本語見出しの2段構成
- **リスト+アイコン**: 資格一覧で fa-certificate アイコンをバレットに使用
- **画像リビール**: id="revealimg" 等のクラスでスクロール時の画像表示アニメーション

## アニメーション / インタラクション

- **appear クラス**: スクロール連動のフェードインアニメーション（全セクションに適用）
- **画像リビール**: revealimg ID による画像のスクロール連動表示
- **ヒーロー動画**: autoplay, muted, loop の背景動画（縦型ピラティス映像）
- **アコーディオン**: Q&Aセクションの details/summary による開閉
- **モーダルメニュー**: ハンバーガーメニュー -> モーダルオーバーレイ（data-modal="modal-menu"）
- **フェードマスク**: 横スクロール領域の端にフェード効果（id="fade-mask-32px"）

## CTA配置パターン

| 位置 | 種類 | 文言 |
|------|------|------|
| ヘッダー横（モバイル固定） | メニュー内CTA | 「かんたんWeb予約 / 体験レッスンを予約する / （50分5,500円）」 |
| ヒーローセクション下 | メインCTA | 「体験レッスン 50分 5,500円（税込） / 姿勢の変化をたった50分で体感！」 |
| 体験レッスンの流れ内 | テキストリンク | 「体験レッスンを予約する」 |
| 体験レッスンの流れ下 | ボタン | 「体験レッスンの内容・持ち物を確認する」 |
| お問い合わせセクション | 背景画像CTA | 「お問い合わせ」 |
| 固定フッターバー | 常時表示CTA | 「体験レッスンを予約する（50分5,500円）」+ LINE + 予約ボタン |

合計: **6箇所以上** のCTA配置。特に固定フッターCTAが常時表示で予約導線を確保。

## コピーライティングの特徴

- **キャッチコピー**: 「身体が整う パーソナル マシンピラティス」-- シンプルで機能的
- **価格訴求**: 「5,500円」を大きく表示、「姿勢の変化をたった50分で体感！」で即効性をアピール
- **安心訴求**: 「完全個室／女性専用」「全員が有資格者」「子供連れ歓迎」
- **権威付け**: 「スポーツ健康科学修士 監修」「科学的根拠に基づいたアプローチ」
- **不安解消**: FAQ で具体的な質問に回答（持ち物、キャンセル、男性不可等）

## 真似したいポイント

1. **固定フッターCTA**: 常時表示の予約バーで離脱を防止。LINE連携も同時に提示
2. **英語ラベル+日本語見出し**: セクション構成が視覚的に美しく、スキャンしやすい
3. **ビフォーアフター**: 体験レッスン1回の変化を具体的に見せる手法
4. **横スクロールステップ**: 体験の流れを横スクロールカードで表現（モバイルフレンドリー）
5. **画像リビール**: スクロール連動の画像表示で視覚的な楽しさを演出
6. **資格一覧の見せ方**: アイコン付きリストで信頼性を高める
7. **ホームエクササイズ動画**: サービスの付加価値をサンプルページで具体的に提示
