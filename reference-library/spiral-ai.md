## レイアウト手法

- **ダークモード全面採用**: 全セクション通して黒背景。テック企業の先進性を表現
- **スティッキー/パララックス**: sticky クラスでスクロール連動のパララックス効果
- **自動カルーセル（マーキー）**: 横方向に自動スクロールする画像帯。transition-duration で速度制御
- **2カラムCTA**: CONTACT と RECRUIT を同じレイアウトで並列配置
- **3Dキャラクター画像**: CTAセクションにキャラクターイラストを配置
- **マルチヘッダー**: 初期表示用・固定用・モバイル用の3種類のヘッダーを使い分け
- **フルスクリーンFV**: ファーストビューが画面全体を使う

## アニメーション / インタラクション

- **appear クラス**: スクロール連動フェードイン（全セクション）
- **スクロールダウンインジケーター**: 「SCROLL DOWN」+ アイコンでスクロール誘導
- **パララックス（sticky）**: スクロール位置に連動した背景画像の移動
- **自動カルーセル**: translateX(-100%) + transition-duration で実装。13秒/30秒ループ
- **マーキーバナー**: 装飾的な横スクロール帯
- **ヘッダー切替**: スクロール位置で初期ヘッダーから固定ヘッダーに切替

- **固有名詞の活用**: 「感情特化型LLMエンジン Geppetto」（ピノキオの職人の名前）

- **括弧書きの補足**: (Get in Touch) / (Join Us!) で英語の副テキスト

## 真似したいポイント

1. **ダークモード全面採用**: テック企業の先進感を全面に出すデザイン
2. **パララックス+スティッキー**: sticky クラスによるスクロール連動の没入感
3. **自動マーキーカルーセル**: CSS transition-duration のみで実装する横スクロール帯
4. **3種類のヘッダー**: 初期/固定/モバイルの使い分けでUXを最適化
5. **CONTACT+RECRUIT並列**: 2つの異なるCTAを同じデザインパターンで配置
6. **SVGロゴ+アニメーション**: ブランドロゴをSVGで表示し、アニメーション可能に
7. **マルチ言語対応**: EN切替ボタンの配置（グローバル企業の印象）
