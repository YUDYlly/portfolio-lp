# PLAID ALPHA

| 項目 | 内容 |
|------|------|
| URL | https://alpha.plaid.co.jp/ |
| 業種 | SaaS / CXコンサルティング |
| ターゲット | 企業のマーケティング担当者・CX責任者 |
| 親会社 | 株式会社プレイド（CXプラットフォーム KARTE） |
| ビルドツール | STUDIO（Nuxt.js ベース） |
| テーマ | プロフェッショナル・先進性・信頼 |

## カラーパレット

| 用途 | カラー | 備考 |
|------|--------|------|
| メインカラー | ブラック / ダークネイビー | 背景・テキスト。プロフェッショナルな印象 |
| アクセントカラー | ライトグレー / シルバー | 区切り線・カード背景 |
| テキスト | ホワイト（暗背景時） / ブラック（明背景時） | コントラスト重視 |
| 背景 | ホワイト / ダークグレー（セクションで切替） | 明暗のセクション交互 |
| CTA | ダーク系ボタン | 「お問い合わせ」ボタン |

## フォント

- **英語**: サンセリフ系（SVG画像でナビゲーション文字を表示）
- **日本語**: ゴシック体系
- **ナビゲーション**: テキストではなくSVG画像で各メニュー項目を表示（独特）

## セクション構成（上から順に）

1. **ヘッダー** -- ナビゲーション（SVG画像リンク）: Strength / Service / Works / Seminar / News / Recruit / Contact
2. **ヒーロー** -- 「PLAID ALPHA WITH KARTE」ロゴ + キャッチコピー + スクロールインジケーター
3. **サービス概要** -- 「顧客中心の価値創造であるべきビジネスを」+ CX変革の説明
4. **ニュース/コラム** -- カード形式の記事リスト（画像+日付+カテゴリ+概要）
5. **セミナー情報** -- イベントカード（日付+タイトル+リンク）
6. **お問い合わせ** -- フォーム埋め込み + 説明テキスト
7. **フッター** -- ロゴ + 運営会社リンク + KARTEリンク + プライバシーポリシー + コピーライト

## レイアウト手法

- **SVGナビゲーション**: テキストではなくSVG画像でナビ項目を表現（デザインの一貫性を保つため）
- **カード型ニュース**: 画像+メタ情報+概要テキストのカードレイアウト
- **明暗セクション交互**: 白背景と暗背景のセクションを交互に配置
- **横並びイベントカード**: セミナー情報を横並びカードで表示
- **フルスクリーンセクション**: 各セクションがビューポート幅いっぱいに展開

## アニメーション / インタラクション

- **appear クラス**: スクロール連動のフェードインアニメーション
- **スクロールインジケーター**: ヒーロー下部のスクロール誘導アニメーション
- **ホバーエフェクト**: ニュース・セミナーカードのホバー状態
- **固定リンクボタン**: 画面右下の固定位置ボタン（image link fixed クラス）

## CTA配置パターン

| 位置 | 種類 | 文言 |
|------|------|------|
| ヘッダー | ナビリンク（SVG） | 「Contact」 |
| ニュースセクション下 | テキストリンク | 「もっと見る」 |
| セミナーセクション下 | テキストリンク | 「もっと見る」 |
| お問い合わせセクション | フォーム | 問い合わせフォーム埋め込み |
| 画面右下固定 | フローティングボタン | 固定CTAボタン |

合計: **5箇所**。BtoB SaaS らしく、押し付けがましくないCTA設計。

## コピーライティングの特徴

- **BtoB向け堅実なトーン**: 「顧客中心の価値創造であるべきビジネスを」
- **専門用語の適切な使用**: CX、データ・AI活用、顧客体験設計
- **プレイドとの関係性**: 「プレイドが積み上げてきた知見・経験に基づき」で親会社の権威を活用
- **一気通貫**: 「全体計画/設計から実行までを一気通貫で支援」
- **KARTE連携**: 自社プロダクトとの連携を自然にアピール

## 真似したいポイント

1. **SVGナビゲーション**: テキストではなくSVG画像でナビを表現。フォントの問題を回避しつつデザインの一貫性を確保
2. **明暗セクション交互配置**: 視覚的なリズムを生む手法
3. **ニュース+セミナーの併置**: 情報発信の2軸（コラム/イベント）を明確に分離
4. **固定フローティングボタン**: 控えめだが常にアクセス可能なCTA
5. **シンプルな構成**: BtoB SaaS は情報過多になりがちだが、セクション数を絞って集中させている
6. **フォーム直埋め込み**: お問い合わせセクションにフォームを直接配置（別ページ遷移なし）
