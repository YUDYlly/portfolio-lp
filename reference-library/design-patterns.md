# デザインパターン集 -- 業種横断リファレンス

> 6つの参考LPから抽出した、再利用可能なデザインパターンの体系的まとめ。
> LP制作時に「何をどう作るか」の判断材料として活用する。

---

## 1. ヒーローセクションのパターン

### パターンA: スライダー型（フェード切替）
**使用LP**: 庭屋サンガーデン / 溝田建築設計

複数の写真をフェードで切り替える王道パターン。施工事例が多い業種に適する。

```
実装: Swiper.js (swiper-fade) / Splide.js (splide--fade)
枚数: 3枚が標準
切替速度: 自動（5-8秒間隔が目安）
```

**構成要素**:
- 全画面背景スライダー
- キャッチコピー（SVG画像 or テキスト）
- サブコピー
- Scroll Down インジケーター

### パターンB: 背景動画+テキスト型
**使用LP**: neuler pilates

動画で雰囲気を伝えつつ、テキストで情報を提供する。サービス体験を見せたい業種に適する。

```
実装: <video> タグ (autoplay, muted, loop, playsinline)
動画: 縦型推奨（モバイルファースト）
フォーマット: MP4 / WebM
```

**構成要素**:
- 背景動画（縦型）
- キャッチコピー
- 特徴バッジ（3つ程度）
- CTA（価格付き）

### パターンC: 横スクロールパネル型
**使用LP**: laughful hair

横方向にスクロールする没入感のあるパターン。ブランディング重視のサイトに適する。

```
実装: CSS transform + JS スクロール連動
特徴: 通常の縦スクロールと異なる体験を提供
```

**構成要素**:
- 大きなタイトル（テキストバンドオーバーレイ）
- 背景動画
- ビジョンテキスト

### パターンD: ダークFV+スクロール誘導型
**使用LP**: Spiral AI / PLAID ALPHA

暗い背景にテキストのみ。テクノロジー企業やBtoBに適する。

```
実装: フルスクリーンdiv + テキスト + SCROLL DOWN アニメーション
背景: ブラック or ダークグレー
テキスト: ホワイト
```

**構成要素**:
- ブランドステートメント（短い1-2文）
- SCROLL DOWN インジケーター
- 固定ヘッダー（スクロール後表示）

### 業種別推奨

| 業種 | 推奨パターン | 理由 |
|------|-------------|------|
| 美容・ジム | B (動画) or C (横スクロール) | 体験の雰囲気を動画で伝える |
| SaaS・テック | D (ダーク) | 先進性・プロフェッショナル感 |
| 建設・造園 | A (スライダー) | 施工事例の写真を見せる |
| 飲食・小売 | B (動画) or A (スライダー) | 商品・空間の魅力を視覚的に |

## 2. セクション見出しのパターン

### パターン1: 英語ラベル + 日本語見出し（最多使用）
**使用LP**: neuler pilates / laughful hair / PLAID ALPHA / 溝田建築設計

```html
<p class="section-label-en">About</p>
<h2 class="section-title-ja">neuler pilatesの特長</h2>
```

英語ラベルは装飾的要素として、日本語見出しが実質的な見出し。`aria-hidden="true"` を英語ラベルに付与するとアクセシビリティ的に適切（溝田建築設計の手法）。

### パターン2: 縦書き見出し + 英語括弧付きサブ
**使用LP**: 庭屋サンガーデン

```html
<hgroup class="c-title-vt">
  <h2 class="c-title-vt-ja">
    <span>庭は人生を、</span>
    <span>豊かにする灯火</span>
  </h2>
  <p class="c-title-vt-en">( Concept )</p>
</hgroup>
```

和風テイストに最適。英語サブテキストを括弧で囲む表現が特徴的。

### パターン3: 漢字一文字 + 英語読み
**使用LP**: 庭屋サンガーデン

```html
<h2>趣<span>( Design )</span></h2>
```

コンセプトを漢字一文字で象徴化する手法。日本語の美意識を活かしたデザイン。

### パターン4: ナンバリング付き
**使用LP**: laughful hair / 溝田建築設計

```html
<p>(01)</p>
<h3>タイトル</h3>
```

価値観やステップを順序付きで見せる。構造が明確で読みやすい。

## 3. カードレイアウトのパターン

### パターンA: ニュース/記事カード
**使用LP**: PLAID ALPHA / 溝田建築設計

```
[画像] [メタ情報（日付+カテゴリ）] [タイトル/概要]
```

```html
<article class="c-card-article">
  <div class="c-card-article__media"><img></div>
  <div class="c-card-article__body">
    <div class="c-tag-article">
      <p class="c-tag-article__tag">お知らせ</p>
      <p class="c-tag-article__day"><time>2025/10/23</time></p>
    </div>
    <p class="c-card-article__title">タイトル</p>
  </div>
</article>
```

### パターンB: 施工事例カード
**使用LP**: 溝田建築設計

```
[写真] [No.XXX] [タイトル] [カテゴリタグ群]
```

スライダー内に配置してスワイプ可能にするパターンが多い。

### パターンC: 特長カード（画像+テキスト）
**使用LP**: neuler pilates / laughful hair

画像とテキストを交互に配置。左画像+右テキスト / 右画像+左テキストを交互に繰り返す。

### パターンD: スタッフ紹介カード
**使用LP**: neuler pilates / laughful hair

```
[写真] [名前（日英）] [資格リスト] [自己紹介文]
```

### パターンE: CTAリンクカード
**使用LP**: 溝田建築設計 / 庭屋サンガーデン

背景画像 + タイトル + 矢印アイコンの組み合わせ。セクション間の導線として使用。

## 4. CTAのパターン

### パターン1: 固定フッターバー（最強の予約導線）
**使用LP**: neuler pilates / laughful hair

画面下部に常時表示される予約/問い合わせバー。離脱防止に最も効果的。

```
構成: [予約ボタン] + [LINE/電話] + [メニュー]
配置: position: fixed; bottom: 0;
```

### パターン2: 価格付きCTA
**使用LP**: neuler pilates

```
体験レッスン 50分
5,500 円（税込）
姿勢の変化をたった50分で体感！
[体験レッスンを予約する]
```

価格を大きく表示 + 訴求テキスト + ボタンの3層構造。

### パターン3: テキストリンク + 矢印
**使用LP**: 庭屋サンガーデン / 溝田建築設計 / Spiral AI

```html
<a class="c-link" href="/page/">
  <span class="c-link__icon">矢印</span>
  <span class="c-link__label">一覧を見る</span>
</a>
```

控えめだが確実に導線を確保するパターン。各セクション末尾に配置。

### パターン4: フローティングボタン
**使用LP**: PLAID ALPHA

画面右下に固定表示される小さなボタン。BtoBサイトに適する。

### パターン5: 2カラムCTA（問い合わせ+採用）
**使用LP**: Spiral AI

```
[CONTACT]          [RECRUIT]
お問い合わせ       採用情報
[ボタン]           [ボタン]
```

同じレイアウトで2つの異なるCTAを並列配置。

### 業種別CTA配置ガイドライン

| 業種 | 推奨CTA数 | 主要CTA | 補助CTA |
|------|-----------|---------|---------|
| 美容・ジム | 5-7箇所 | 予約ボタン（固定バー） | LINE / 電話 |
| SaaS | 3-5箇所 | お問い合わせフォーム | セミナー申込 |
| 建設 | 8-10箇所 | 問い合わせ（Web+電話） | モデルハウス見学 |
| 造園 | 6-8箇所 | 問い合わせ | 各セクション More |

## 6. カラーパレットのパターン（業種別傾向）

### 美容・ヘルスケア業界
```
メイン: ベージュ / オフホワイト / ウォームトーン
アクセント: ゴールド / ブラウン
テキスト: ダークブラウン〜ブラック
背景: アイボリー / ウォームホワイト
印象: 温かみ・安心感・ナチュラル
```

### SaaS・テック業界
```
メイン: ブラック / ダークネイビー
アクセント: ホワイト / シルバー
テキスト: ホワイト（暗背景）/ ブラック（明背景）
背景: ダークグレー〜ブラック / ホワイト（交互）
印象: 先進性・プロフェッショナル・信頼
```

### 建設・造園業界
```
メイン: ホワイト / ダークグリーン
アクセント: ゴールド / ウォームベージュ
テキスト: ブラック / ホワイト（暗背景時）
背景: ホワイト / 暗い背景写真（交互）
印象: 清潔感・自然・職人気質
```

## 7. タイポグラフィのパターン

### 和洋融合ペアリング（推奨）

| 日本語 | 英語 | 使用LP | 適する業種 |
|--------|------|--------|-----------|
| しっぽり明朝 | Garamond Premier Pro Display | 庭屋サンガーデン | 造園・和食・伝統工芸 |
| ゴシック体 | サンセリフ（システムフォント） | PLAID ALPHA / Spiral AI | SaaS・テック |
| 明朝体系 | セリフ系 | laughful hair | 美容・ライフスタイル |
| ゴシック体 | システムフォント | 溝田建築設計 | 建設・不動産 |

### フォントサイズの傾向

| 要素 | 目安サイズ | 備考 |
|------|-----------|------|
| キャッチコピー | 32-48px（SP: 24-32px） | 太字・インパクト重視 |
| セクション見出し | 24-32px | 英語ラベルは小さめ |
| 本文 | 14-16px | 行間 1.6-1.8 |
| CTA文言 | 14-18px | 太字 |
| 注釈・キャプション | 12-13px | ライトグレー |

## 8. アニメーション/インタラクションのパターン

### 全LP共通: スクロール連動フェードイン
```
実装: Intersection Observer / appear クラス
効果: 要素がビューポートに入ったときにフェードイン
使用率: 6/6 LP（全サイトで使用）
```

### スライダー/カルーセル
```
ライブラリ: Swiper.js / Splide.js / CSS transition
パターン:
  - フェード切替（ヒーロー）
  - 横スライド（施工事例・スタッフ）
  - 自動マーキー（装飾帯）
使用率: 5/6 LP
```

### パララックス
```
実装: GSAP / CSS transform + JS
対象: 背景画像・装飾要素
使用率: 3/6 LP（サンガーデン、溝田、Spiral AI）
```

### スムーススクロール
```
ライブラリ: Lenis
使用率: 1/6 LP（サンガーデン）だが、高級感に大きく寄与
```

### ローディングアニメーション
```
実装: SVG circle ストロークアニメーション
使用率: 1/6 LP（サンガーデン）
効果: サイトの第一印象を格上げ
```

## 9. 共通パターンまとめ（全LPに見られる要素）

1. **英語+日本語の二段見出し**: 6/6 LP で使用。業種を問わない鉄板パターン
2. **スクロール連動アニメーション**: 6/6 LP で使用。もはや標準装備
3. **ハンバーガーメニュー（モバイル）**: 6/6 LP で使用
4. **セクション末尾のMore/CTAリンク**: 5/6 LP で使用
5. **写真+テキストの交互レイアウト**: 4/6 LP で使用
6. **カード型コンテンツ**: 5/6 LP で使用（ニュース・事例・スタッフ）
7. **WebP画像フォーマット**: 5/6 LP で使用（パフォーマンス最適化）
8. **Lazy Loading**: 4/6 LP で使用（loading="lazy" or data-src）
9. **SNS/LINE連携**: 3/6 LP で使用
10. **電話番号の click-to-call**: 2/6 LP で使用（ローカルビジネス）
